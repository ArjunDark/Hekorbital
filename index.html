notes
Ingress follows preprocess/reference/Cubesatsim_dataintake.py: raw frame → 3-slot PSRAM ring → area-average resize → INT8 (clip(x−128, −128, 127)) → 4.2 MB SRAM guard → features measured on the de-quantised tensor.

Tiles are public-domain satellite imagery (NASA / USGS / NOAA / ESA via Wikimedia Commons), cycled in a fixed order with a deterministic crop offset per pass.

canvas pixels unavailable

The browser is refusing to expose canvas pixels to the page. That happens when index.html is opened straight off disk (file://) — images loaded from the filesystem taint the canvas and the preprocessing stage cannot read them.

Serve the folder over HTTP:

cd sat-img-pipe
python3 serve.py
# open http://localhost:8000
