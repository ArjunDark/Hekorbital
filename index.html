Notes
Frame bytes are a real JPEG encode of the tile. Re-encode sizes on compression use the encoder model b = b₀·(q/q₀)^1.9. Effective rank eff = priority · (0.5 + 0.5·q/q₀), so compression visibly demotes a frame.

Tiles are real public-domain satellite imagery (NASA / USGS / NOAA / ESA via Wikimedia Commons), cycled in a fixed order — no random generation. Each pass applies a small deterministic crop offset so a revisited tile is not byte-identical.

Pixels unreadable

The browser is refusing to hand canvas pixels to the page. That happens when index.html is opened straight off disk (file://) — images loaded from the filesystem taint the canvas, and the preprocessing stage cannot read them.

Serve the folder over HTTP instead:

cd sat-img-pipe
python3 serve.py
# then open http://localhost:8000
